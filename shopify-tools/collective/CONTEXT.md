# Project Context & Workflow Guide

## Overview
This repository processes Shopify inventory exports for **Kicks Collective PA** (KCP) and future suppliers/vendors, normalizing product variants, SKUs, sizes, box conditions, titles, and taxonomy categories for Shopify Flow workflows.

---

## File Structure

- **`importer.js`**: Core Shopify Flow / Run Code ES Module function (`export default function main(input)`).
  - Defines supplier configs (`SUPPLIERS`), Taxonomy GIDs (`CATEGORY_GIDS`), composite option parsing, title formatting, and error collection.
- **`process_inventory.mjs`**: Local runner script to process CSV files.
  - Input: `kc-inventory.csv`
  - Output: `kc-output.csv`
  - Parses Shopify export CSV rows, aggregates parent product metadata by `Handle`, maps inputs to the structure expected by `importer.js`, overrides vendor to `"Kicks Collective PA"`, and outputs processed records with `input` fields prefixed.
- **`importer.test.mjs`**: Unit test suite using Node.js built-in runner (`node:test`).
  - Contains 12 generalized tests covering SKU generation (`{PREFIX}-{variantId}`), supplier prefixing, size text parsing, box/condition mapping, taxonomy categories, option name dispatches, and defensive input handling.
- **`kc-inventory.csv`**: Raw input inventory export.
- **`kc-output.csv`**: Processed output CSV generated by `process_inventory.mjs`.
