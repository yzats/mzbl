# Project Context & Workflow Guide

## Overview
This repository processes Shopify inventory exports for **Kicks Collective PA** (KCP) and future suppliers/vendors, normalizing product variants, SKUs, sizes, box conditions, titles, and taxonomy categories for Shopify Flow workflows.

**Shared** size conversion, Body reader, box map, category and description rules: [`SHARED_NORMALIZATION.md`](SHARED_NORMALIZATION.md).  
**Supplier-specific** sources and condition vocabulary: **`{PREFIX}_NORMALIZATION_RULES.md`** (e.g. [`KCP_NORMALIZATION_RULES.md`](KCP_NORMALIZATION_RULES.md)).

---

## File Structure

- **`importer.js`**: Core Shopify Flow / Run Code ES Module (`export default function main(input)`).
  - Shared: `BOX_MAP`, Body reader, size parse/convert, category, title size suffix, description helpers.
  - Per supplier (`SUPPLIERS`): prefix, parser name, shoe-name strategy, category source, option names — plus parser functions and condition vocabulary (e.g. `KCP_CONDITION_MAP`).
  - Reads only these Flow input fields: `productVariant { id sku selectedOptions { name value } product { vendor title descriptionHtml productType category { name } } }`.
- **`process_inventory.mjs`**: Local runner script to process CSV files.
  - Usage: `node process_inventory.mjs [input.csv] [output.csv]`
  - Defaults: `kc-inventory.csv` → `kc-output.csv`
  - Parses Shopify export CSV rows, aggregates parent product metadata by `Handle`, maps inputs to the structure expected by `importer.js` (Body passed as `descriptionHtml`), overrides vendor to `"Kicks Collective PA"`, and outputs processed records with `input` fields prefixed.
- **`importer.test.mjs`**: Unit test suite using Node.js built-in runner (`node:test`).
- **`SHARED_NORMALIZATION.md`**: Shared size / Body reader / box / category / description rules.
- **`KCP_NORMALIZATION_RULES.md`**: KCP Body template, condition/box/title rules and import errors.
- **`kc-inventory.csv`**: Raw input inventory export.
- **`kc-output.csv`**: Processed output CSV generated by `process_inventory.mjs`.
